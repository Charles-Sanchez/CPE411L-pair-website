# CPE411L-pair-website
Hands-On Activity 2: Build a Simple Website + Github Workflow (Pair Activity)

Activity Goal:
 Build a simple website from scratch(Any tools / language) and use Github Workflow for every change:
    feature branch >> commits >> pull requests >> partner review >> merge to main 
 Then publish design using GitHub Pages.

 Website Requirements (Minimum)
    - Has a clear Home Page (title + intro)
    - Has 2 or more sections / pages
    - Has basic styling
    - Works on mobile
